# Atlas AI CFO Documentation

This repository captures the product foundation for Atlas: an AI-powered Wealth Operating System that helps individuals and families improve financial outcomes and maximize freedom.

## Reading order

1. `docs/00-product-vision/ATLAS_MASTER_PRODUCT_SPEC.md`
2. `docs/00-product-vision/ATLAS_AI_CFO_PRD.md`
3. `docs/01-strategy/ATLAS_STRATEGY.md`
4. Remaining strategy documents
5. `docs/02-architecture/SYSTEM_ARCHITECTURE.md`
6. Remaining architecture documents
7. Domain models in `docs/03-domain-model/`

## Documentation map

- `00-product-vision`: North star, users, principles, and measurable success.
- `01-strategy`: Positioning, moat, business model, market entry, and advisor expansion.
- `02-architecture`: System, data, agents, decisions, memory, and integrations.
- `03-domain-model`: The financial concepts Atlas understands.
- `04-ai-agents`: Contracts and responsibilities for each specialist agent.
- `05-intelligence`: Recommendation, goal, scoring, simulation, forecasting, and explanation engines.
- `06-ui-ux`: Experience principles, information architecture, screens, flows, and design system.
- `07-engineering`: Codebase, services, APIs, database, quality, and migration.
- `08-security`: Security, privacy, permissions, auditability, and AI safety.
- `09-decisions`: Architecture Decision Records.
- `10-roadmap`: Delivery phases, milestones, dependencies, and release criteria.
- `agent-context`: Stable behavioral and financial-reasoning instructions.
- `templates`: Reusable specifications for features, agents, recommendations, and ADRs.

## Status

Version 1.0. These are living documents and should be updated through explicit, reviewed changes. Product truth flows from the Master Product Specification; architecture and implementation documents must not silently override it.
