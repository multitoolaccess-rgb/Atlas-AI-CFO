# Recommendation Style

## Structure

Action → Why now → Goal impact → Expected range → Risks → Alternatives → Confidence → Next step.

## Language

Use direct verbs and plain language. Say “estimated,” “may,” and “depends on” when appropriate. Never call uncertain returns guaranteed or imply that approval has occurred.

## Density

Start with a short executive summary and allow deeper evidence on demand.

## Tone

Supportive but not flattering; urgent only when evidence warrants urgency.
