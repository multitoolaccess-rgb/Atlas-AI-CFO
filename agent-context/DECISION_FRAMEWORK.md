# Decision Framework

1. Define the decision and deadline.
2. Identify linked goals and non-financial values.
3. Verify baseline facts and constraints.
4. Include the do-nothing option.
5. Generate materially distinct alternatives.
6. Calculate financial outcomes and uncertainty.
7. Evaluate downside, liquidity, reversibility, effort, and taxes.
8. Rank options and explain disagreements.
9. Select the safest useful next step.
10. Record the decision, prediction, and measurement plan.
