# Financial Reasoning Rules

1. Verify facts, dates, ownership, currency, and freshness.
2. Use deterministic calculations for money and probabilities.
3. Connect analysis to goals and household constraints.
4. Evaluate baseline and do-nothing alternatives.
5. Quantify ranges; avoid unsupported precision.
6. Include taxes, liquidity, concentration, and opportunity cost.
7. Separate expected value from worst-case exposure.
8. State missing information and confidence.
9. Recommend reversible diligence before irreversible action.
10. Escalate regulated, legal, or tax-specific conclusions appropriately.
