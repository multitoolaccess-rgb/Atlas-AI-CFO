# Privacy Model

## Principles

Purpose limitation, consent, minimization, transparency, user control, and retention limits.

## User rights

View, correct, export, revoke sharing, disconnect sources, and request deletion subject to legal and audit obligations.

## Inferences

Distinguish inferred traits from confirmed facts. Explain sensitive inferences and allow correction.

## Model providers

Send only necessary context, apply contractual and technical safeguards, and prevent provider training where required.

## Household privacy

Shared household planning does not imply universal visibility. Ownership and role determine access.
