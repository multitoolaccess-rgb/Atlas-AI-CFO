# Audit Logging

## Events

Authentication, data access, profile changes, recommendations, model calls, approvals, policy changes, executions, integration activity, and administrative actions.

## Event fields

Actor, role, household, action, target, timestamp, source, correlation ID, before and after references, policy result, and outcome.

## Integrity

Audit history is append-only, access-controlled, tamper-evident, retained by policy, and exportable for review.

## Privacy

Record enough to reconstruct actions without placing secrets or unnecessary personal data in logs.
