# AI Safety and Model Risk

## Risks

Hallucination, stale knowledge, prompt injection, overconfidence, bias, data leakage, tool misuse, and automation error.

## Controls

Ground outputs in approved data, validate structured responses, isolate untrusted content, use allowlisted tools, separate calculation services, enforce policies outside the model, and require approvals.

## Evaluation

Financial factuality, citation fidelity, abstention, adversarial inputs, permission boundaries, calibration, and regression suites.

## Monitoring

Model/version traceability, failure metrics, drift, user corrections, and incident review.

## Principle

Models propose; deterministic systems validate; policies authorize; users remain in control.
