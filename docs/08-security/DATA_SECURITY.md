# Data Security

## Principles

Least privilege, defense in depth, encryption, isolation, minimization, and auditable access.

## Controls

Encryption in transit and at rest, managed secrets, environment separation, tenant-scoped authorization, secure backups, vulnerability management, and incident response.

## Financial data

Production data is never used in development without approved de-identification. Logs exclude secrets and unnecessary financial values.

## Integrations

Store tokens in a dedicated vault, request narrow scopes, rotate credentials, and revoke promptly.

## Verification

Threat modeling, dependency scanning, penetration testing, access reviews, restore tests, and security monitoring.
