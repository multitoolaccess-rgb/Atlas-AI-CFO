# AI Agent Overview

Specialists analyze bounded domains; the orchestrator composes findings. Agents do not own canonical financial calculations, permissions, or execution.

## Common contract

Inputs include validated facts, goals, profile, constraints, and task scope. Outputs include findings, evidence, assumptions, confidence, risks, alternatives, and requested follow-up calculations.

## Boundaries

Agents may propose but not silently execute. They must abstain when evidence is inadequate, surface conflicts, and distinguish education from regulated advice.

## Evaluation

Test factual grounding, calculation references, recommendation consistency, calibration, refusal behavior, permission compliance, and adversarial content handling.
