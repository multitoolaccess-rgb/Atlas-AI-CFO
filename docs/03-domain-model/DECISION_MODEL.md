# Atlas Decision Model

**Version:** 1.0

## Purpose

Represent financial choices as first-class records and create a durable learning loop.

## Why decisions matter

Traditional tools store transactions. Atlas also stores why a choice was considered, what options existed, what was predicted, what was chosen, and what happened.

## Decision record

- Question and decision category
- Context and triggering event
- Linked goals
- Constraints and preferences
- Options, including doing nothing
- Evidence and assumptions
- Financial, risk, tax, effort, and opportunity-cost analysis
- Recommendation and confidence
- User decision and rationale
- Approval and execution status
- Expected and actual outcomes

## Lifecycle

Created → Analyzed → Recommended → Approved or rejected → Executed → Measured → Closed or revisited.

## Scoring

Each option is assessed for financial impact, goal alignment, risk, confidence, reversibility, liquidity, effort, timing, and external dependencies.

## Examples

- Reduce a concentrated stock position.
- Retire early.
- Buy or start a business.
- Purchase a property or vehicle.

## Memory principle

Predictions and historical reasoning are immutable. New evidence creates a new version rather than silently rewriting the past.
