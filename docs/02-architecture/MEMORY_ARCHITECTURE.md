# Atlas Memory Architecture

## Memory classes

- Canonical financial records
- Historical snapshots
- User-stated preferences and goals
- Derived observations
- Recommendations and decisions
- Outcomes and calibration
- Conversation context

## Rules

Canonical records outrank derived memory. Every memory has source, timestamp, scope, confidence, and retention policy. Inferences remain distinguishable from user-confirmed facts.

## Retrieval

Retrieve only context relevant to the current user, household, role, and task. Enforce permissions before retrieval, not only before display.

## Lifecycle

Create, validate, use, correct, expire, archive, or delete. Corrections preserve audit history where legally and operationally appropriate.
