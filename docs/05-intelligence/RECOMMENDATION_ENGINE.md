# Recommendation Engine

## Purpose

Convert validated findings and ranked options into clear, actionable recommendations.

## Contract

Every recommendation has a title, action, linked goals, trigger, evidence, impact range, risks, confidence, alternatives, required approvals, expiration, and measurement plan.

## Lifecycle

Candidate → Validated → Ranked → Presented → Accepted, rejected, deferred, or expired → Executed where applicable → Measured.

## Deduplication

Merge overlapping findings, suppress low-value repetition, and explain changed recommendations.

## Quality gate

No recommendation ships if facts are stale, required inputs are absent, policy checks fail, or uncertainty makes the action misleading.
