# Simulation Engine

## Purpose

Compare future outcomes for explicit “what if” scenarios.

## Scenario components

Baseline snapshot, changed assumptions, time horizon, stochastic variables, taxes, inflation, cash flows, and goal outcomes.

## Outputs

Probability distributions, median and downside cases, liquidity path, net-worth path, goal changes, and key sensitivities.

## Reproducibility

Store model version, inputs, seed where applicable, timestamp, and linked decision.

## Guardrail

Never present a simulation as a prediction certainty. Clearly distinguish user input, default assumption, and external estimate.
