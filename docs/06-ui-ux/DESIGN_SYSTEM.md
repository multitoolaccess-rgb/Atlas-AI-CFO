# Atlas Design System

## Character

Calm, precise, premium, and legible. Visual restraint communicates trust.

## Foundations

Use semantic color for status, accessible contrast, tabular numerals for financial values, and consistent units and date formats.

## Components

Goal meter, probability range, recommendation card, risk alert, opportunity card, evidence drawer, scenario comparison, approval panel, and audit timeline.

## Content

Lead with outcome and action. Avoid alarmism, hype, unexplained acronyms, and decorative precision.

## Accessibility

Meet WCAG 2.2 AA, support keyboard navigation, visible focus, reduced motion, screen-reader labels, non-color status cues, and zoom.
