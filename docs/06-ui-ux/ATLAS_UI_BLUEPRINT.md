# Atlas UI Blueprint

## Experience vision

Atlas feels like calm financial Mission Control: forward-looking, decisive, trustworthy, and free from dashboard clutter.

## Primary navigation

Mission Control, Goals, Decisions, Simulations, Investments, Opportunities, Advisor, and Data & Settings.

## Mission Control

Show goal trajectory, probability, top actions, material risks, opportunities, recent changes, and data freshness. Existing flow and trend visualizations become supporting evidence, not the hero.

## Interaction model

Insight → Explanation → Simulation → Decision → Approval → Outcome.

## Trust patterns

Always expose source, timestamp, assumptions, confidence, permissions, and action status.

## Responsive priorities

Mobile supports review and approval; complex modeling and advisor work optimize for larger screens.
