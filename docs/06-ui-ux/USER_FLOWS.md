# User Flows

## Onboarding

Identity and household → goals → data connections → verification → profile and risk → baseline → first actions.

## Recommendation

Notification → summary → evidence → scenario → alternatives → accept, defer, reject, or ask advisor → outcome tracking.

## Simulation

Choose question → load baseline → change assumptions → compare → save → create decision.

## Advisor sharing

Invite → select role and scope → review permissions → advisor accepts → activity audited → revoke anytime.

## Execution

Recommendation → eligibility and policy checks → preview → required confirmation → submit → reconcile → measure.
